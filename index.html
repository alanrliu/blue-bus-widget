    Installation steps

  1. Install Scriptable from the App Store (free).
  2. Tap the copy button above.
  3. Open Scriptable → tap + (top right) → paste → tap ▶ once. It saves itself as Blue Bus.
  4. Long-press home screen → + → search Scriptable → pick Small/Medium (as desired) → Add Widget.
  5. Long-press the new widget → Edit Widget → set Script to Blue Bus.
